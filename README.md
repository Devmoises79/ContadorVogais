## 🧑‍💻 Contador de Vogais
Este projeto é um script simples em Python que conta a quantidade de cada vogal (a, e, i, o, u) em uma frase fornecida pelo usuário.

## 💡 Funcionalidade
- O script solicita que o usuário insira uma frase.

- Ele conta quantas vezes cada vogal (a, e, i, o, u) aparece na frase, ignorando maiúsculas e minúsculas.

- A contagem de cada vogal é exibida ao final.

## 🚀 Como Executar:
- Certifique-se de ter o Python instalado em sua máquina (versão 3.7 ou superior).

- Baixe ou copie o arquivo contador.py.

- Abra o terminal ou prompt de comando e navegue até o diretório onde o arquivo está localizado.

Execute o script com o comando:

```bash
python contador.py
```

- Insira uma frase quando solicitado, e o programa exibirá a contagem de cada vogal.

## 🧠 Conceitos Abordados
- Leitura de entrada de dados com input().

- Uso de dicionários para armazenar contagens.

- Laços de repetição (for) para percorrer os caracteres da frase.

- Manipulação de strings em Python.

## 🛠 Tecnologias Utilizadas
Python (qualquer versão 3.x)

## 📌 Observações
- O script não diferencia maiúsculas de minúsculas (a contagem é feita de forma case-insensitive).

- Caso não haja nenhuma vogal na frase, o valor para essa vogal será 0.
